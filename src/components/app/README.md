# App Components

This folder contains components specific to the Swift Money Transfer application:

- **Money transfer** functionality components
- **User dashboard** components
- **Transaction** related components
- **Financial data** display components
- **App-specific forms** and inputs

## Examples:
- `TransferForm.js` - Money transfer form
- `TransactionHistory.js` - User's transaction list
- `AmountInput.js` - Currency input component
- `RecipientSelector.js` - Choose transfer recipient
- `ExchangeRate.js` - Display current rates
- `ConfirmationModal.js` - Transfer confirmation

These components are used within the actual money transfer application prototype.
