# Main Components

This folder contains components used for:

- **Landing page** components (hero sections, feature lists, etc.)
- **General website** components (headers, footers, navigation)
- **Marketing/promotional** components
- **Shared UI elements** that aren't app-specific

## Examples:
- `Hero.js` - Landing page hero section
- `Header.js` - Site header/navigation
- `Footer.js` - Site footer
- `FeatureCard.js` - Product feature cards
- `Button.js` - General purpose buttons

These components are typically used on pages like:
- Landing page
- About page
- Contact page
- Marketing pages
